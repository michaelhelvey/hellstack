## Machine: Work (Transport4)

### Jira

- Almost always when you make a pull request, you have to have an associated JIRA ticket (this means
  that the pull request name needs the format `[AB-1234]: Pull Request Title`).
- Name git branches after the jira ticket as well, e.g. `ab-1234-some-branch-name`
- Use the `jira` skill to interact with jira.

### Sentry

You should have an authenticated sentry CLI (`sentry auth whoami`). Use it when I ask you to do
stuff with sentry.
