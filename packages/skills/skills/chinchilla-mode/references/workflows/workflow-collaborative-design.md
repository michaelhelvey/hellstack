# Collaborative Design

Apply when the user asks to design something / think through / talk through something with them.

- Figure out with the user where you should save your work. The output of the session should be a
  markdown document. Don't create a new document if one exists already for this purpose.
- Keep responses short and to the point. Think 100-200 words max (less is better), unless I
  explicitly ask for comprehensiveness. Think rapid-fire back and forth, like you'd do with a human.
  I'll ask you to dig into more detail where I want it.
- Show me visually what you are talking about when you can. Show how data / function calls flow
  through the application in visually beautiful way. See the `/show-me` skill.
