---
name: rex
description:
  Use the rex CLI to manage Rex sessions, open tabs, arrange panes, run commands, inspect terminal
  output, and control connected Rex apps.
---

Run `rex skill show` and follow the guide that it prints. The guide comes from the installed Rex
CLI, so it tells you the commands of that version.

If the command fails, the installed Rex version is older than the guide. Start with
`rex whoami --json`, then use `rex --help` and `rex COMMAND --help`.
